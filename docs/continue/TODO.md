# Что осталось сделать в тренажёре (на 8 октября 2026)

## Рабочий набор в этой папке

- `CONVENTIONS.md` — свод правил для агентов, которые пишут разделы: стиль «история с интерактивом»,
  общие функции ядра, CSS-токены, проверка. Пути к scratchpad в нём — от старой сессии; замените на
  временную папку новой сессии.
- `verify.sh ПРЕФИКС ФАЙЛ.html` — проверка одного раздела: SOLO (ядро + ваш файл) и FULL (вся книга)
  во временной папке, общий index.html не трогает. Перед запуском скопируйте скрипт во временную папку:
  он пишет сборки рядом с собой.
- `gloss/*.json` — 481 новый термин для глоссария. Ещё не перенесены в `_parts/p29_gloss.html`
  (формат там: массив `G` и словарь `X`).

## Выкладка

- `node publish.js` — собрать сайт только из готовых разделов. Заглушки скрываются, «Дальше →»
  перескакивает через них.
- `node check.js && node smoke.js` — затем commit и push в main (GitHub Pages).

Содержание каждого раздела — в рекомендациях исследования программы курса (раздел «Новые разделы»
в истории сессии). Кратко:
- reqs — стейкхолдеры, уровни требований, сценарии качества;
- bpmn — симулятор токенов, статусные модели;
- eip — маршруты EIP, маппинг полей;
- cap — оценка «от DAU к RPS», хвосты задержек;
- dwh — строки против колонок, окна;
- dr — «отключи ЦОД», RPO/RTO → стоимость;
- pay — ledger, сверка, таймаут банка;
- cloud — сервер против serverless;
- cases — сокращатель ссылок, лента, чат.
