# Архитектура ПО — интерактивный тренажёр

Монолиты и микросервисы, поддомены и границы, саги, outbox, CQRS, балансировщики, sticky session,
размыкатель цепи, шардирование, канареечные выкатки, душитель легаси — **руками**, а не по слайдам.

Откройте `index.html` двойным щелчком: работает офлайн, ничего устанавливать не нужно, прогресс
сохраняется в браузере.

## Для кого

Для учеников, а не для архитектурного комитета. Поэтому:

- каждая тема сначала объясняется **на кафе, почте и гардеробе**, и только потом называется термином;
- в тяжёлых местах стоит врезка **«Проще говоря»** — одна фраза без жаргона;
- две вкладки сделаны как игры: «Кафе растёт» и «Смена дежурного»;
- варианты ответов перемешиваются, так что «правильный обычно второй» не работает.

На вкладке «Практика» внизу есть кнопка «Сформировать код» — впишите имя, получите разбивку по

## Связь с платформой

Тренажёр отчитывается о набранных баллах платформе T-shape, когда открыт внутри неё. Наружу уходит
только факт: код задания и балл. Что этот код подтверждает в графе навыков, знает платформа — у неё
манифест. Протокол `trainer/1`, обмен через `postMessage`. Вне платформы работает так же, просто
некому отчитываться.

## Как устроен репозиторий

Итоговый `index.html` — один самодостаточный файл без зависимостей и без сборки. Он **собирается из
частей**, чтобы с ним можно было работать:

```
_parts/p01_head.html      — CSS и токены темы
_parts/p02_header.html    — шапка, вкладки и ядро: прогресс, движки заданий
                            (renderTasks, renderSort, renderPatterns, shuffleBy), мост к платформе
_parts/p03..p29_*.html    — по файлу на вкладку: разметка + свой скрипт рядом
_parts/p30_tail.html      — переключение вкладок, тема, подвал
```

```sh
sh build.sh      # склеить _parts/*.html в index.html (порядок — по именам файлов)
node check.js    # синтаксис скриптов, битые data-goto, вкладки без панелей
node smoke.js    # прогон в jsdom: кликает все кнопки на всех вкладках, ловит runtime-ошибки
```

`smoke.js` требует jsdom — путь к нему прописан в начале файла.

**Важно:** общие функции (`renderTasks`, `renderSort`, `renderPatterns`, `shuffleBy`, `confetti`,
`Progress`) живут в `p02_header.html` и должны быть объявлены раньше, чем их вызовет любая вкладка.
Скрипт вкладки выполняется сразу при разборе страницы, поэтому «объявлю ниже» не сработает.

## Как добавить вкладку

1. Новый файл `_parts/pNN_name.html`: `<section class="panel" id="name">…</section>` и `<script>` рядом.
   Чтобы вставить вкладку между существующими, используйте букву: `p03a_life.html` встанет между
   `p03_` и `p04_`.
2. Кнопка в `_parts/p02_header.html` с `data-tab="name"`.
3. `Progress.register('ключ', максимум, 'Название')` — иначе баллы не попадут в шапку.
4. `sh build.sh && node check.js && node smoke.js`.
